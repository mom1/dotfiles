# Dotfiles

Managed with [chezmoi](https://www.chezmoi.io/).

## Install

```bash
curl -fsSL https://raw.githubusercontent.com/tochkamac/dotfiles/main/install.sh | sh
```

Or clone and run:

```bash
git clone https://github.com/tochkamac/dotfiles.git ~/.local/share/chezmoi
cd ~/.local/share/chezmoi && ./install.sh
```

## Update

```bash
chezmoi update
```
